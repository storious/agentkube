# Schemas

`agul-web-search-result-v1.schema.json` describes structured search, page
opening, and in-page find results returned by the Web Search Plugin.

[Agul owns `agul/handoff/v1`](https://github.com/storious/agul/blob/main/schemas/handoff-v1.schema.json),
and Agulater owns package, catalog, harness, pool, and prepared-runtime schemas.
AgentKube links to those contracts instead of maintaining divergent copies.
