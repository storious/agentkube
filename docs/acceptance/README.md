# 亲自体验 Agul

你负责判断好不好用，不负责构建、拼命令、写 Pool JSON 或重新搭环境。
维护者先准备好本机候选程序和场景；以下入口只打开已有环境，不构建、不安装。

## 打开一次，选场景

Windows 可以双击本目录的 **start.cmd**；或者在仓库根目录执行一次：

```powershell
.\docs\acceptance\start.cmd
```

Linux/macOS 使用 `python3 docs/acceptance/experience.py`。
这里只需要 Python（也是 AgentKube Plugins 已有的依赖），不需要 Bun、Node.js
或 Cargo。没有准备好时应由维护者处理，不要求你临时安装构建工具。

菜单选数字即可。每次退出 Agul 后回到菜单；重新打开仍是原来的环境和会话。
所有练习文件与记录留在忽略目录 `.tmp/acceptance-experience/`，不会修改产品源码。

| 场景 | 进入 Agul 后说什么 | 重点看什么 |
| --- | --- | --- |
| 1 DeepSeek minimal | 开始验收 | 读文件、运行测试、Markdown、四个工具 |
| 2 GLM Coding Plan | 开始验收 | 真正回答并调用工具；`/cost` 为套餐额度，`/usage` 查看 tokens |
| 3 ChatGPT + Web | 开始验收 | 当前事实和真实来源链接，使用 Codex 额度 |
| 4 AgentKube 网页 | 网页验收 | 无搜索引擎配置也能打开网页 |
| 5 本地 + DeepSeek 子 Agent | 委派验收 | GLM master 调用两个真实子 Agent 并复核结果 |
| 6 / 7 续聊 / 选择历史 | 自由继续上一场景 | 不记 ID、不丢历史，不必重建环境 |
| 8 账户登录 | 跟随官方登录流程 | 仅需要登录或专门验收登录时选择 |

DeepSeek / GLM 自动读取已有 API key；缺少时只影响对应场景，不阻塞整个菜单。
ChatGPT 保留宿主机已有登录，不会自动退出或强制反复登录。
本地模型优先复用环境变量或本机已有的验收配置；缺少时只问一次地址和模型名，
保存在忽略目录，之后直接复用。菜单的 `L` 可以修改。
本地 worker 使用 medium、32k 上下文和 600 秒超时，冷启动几分钟时可继续编辑输入。

## 你只需判断这些

- [ ] 布局舒适：独立页面、有留白，消息、推理、工具与 Markdown 容易分辨。
- [ ] 输出时输入框和状态栏不消失；`/`、`@`、多行编辑、滚动、缩放正常。
- [ ] steer、`/stop`、Ctrl+C 可用；退出恢复 shell，续聊不用记 ID。
- [ ] DeepSeek、GLM Coding Plan、ChatGPT 三种连接确实可用，费用/额度不混淆。
- [ ] 网页和子 Agent 的实际结果可用，进度可读；master 会复核补丁和测试。

退出每个场景后，可填“满意 / 有问题 / 暂不判断”和一句备注。程序退出码为零
**不等于验收通过**；这些手工记录保存到本机 `results.jsonl`。
遇到明显问题就记下、截图或停下，不必完成剩余清单才能反馈。

构建、无 Bun 安装、产物内容、账本字段和故障注入是
[维护者工作](maintainer-runbook.md)，不是以上人工体验的前置作业。
当前菜单只是本机体验，不代表全新机器的公网下载路径已经验证；
安装链路也必须由维护者单独实测。历史测试记录不能代替你这次体验。

没有你的明确批准，不推进 `main`、不打 tag、不发布。
