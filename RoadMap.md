# Roadmap

AgentKube grows from extensions that solve real problems for Agul users.

- [x] Run the `grilling` Skill end to end through the small ARI example.
- [x] Package `grill-me` and `grilling` for easy installation.
- [x] Ship Web Search as the first official Plugin and reference implementation.
- [x] Add a repository-maintenance starter with four bounded specialists.
- [x] Add a versioned catalog that Agulater can browse and install from.
- [x] Add a first coordinator extension so one master Agul can send up to five
  bounded tasks to specialist Agul sessions through ARI and return their usage.
- [x] Exercise the coordinator contract with prepared read/write specialists,
  pool limits, structured handoffs, and exact usage aggregation.
- [ ] Let real maintenance workflows shape any future profiles or graphs.
- [ ] Grow Plugins only when an Agul workflow needs a reusable integration.

AgentKube will remain a collection rather than becoming another CLI or agent
runtime.
